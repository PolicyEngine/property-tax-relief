# Interface brief

Visual thesis: a calm editorial research atlas, with PolicyEngine's teal, generous type and a national state grid as the main visual anchor.

Content plan: scope and reference period; searchable national workspace; state profiles and comparison; report and methods; downloadable source data.

Interaction thesis: filtered state grid updates without navigation, program details expand inline, and comparison columns update on state selection. Use short transitions and respect reduced-motion preferences.

The interface must distinguish legal research coverage, model implementation presence, and validated calculations. Do not draw a benefit curve from source maxima or interpolate amounts for unrun scenarios. Missing results must never display as $0.
